# Number List Editor (C++)

A menu-driven C++ program with an `Editor` class for editing a list of numbers stored in an array.

## Features

- Insert a number at a specific index, or without an index
- Delete numbers by position or by range
- Find and replace a number, or replace every match
- Display all the numbers

## Tech stack

C++

## Getting started

```bash
git clone https://github.com/Matiz009/number-list-editor-cpp.git
cd number-list-editor-cpp
g++ "intelligentEditor.cpp" -o intelligentEditor && ./intelligentEditor
```

## Project structure

```
intelligentEditor.cpp   Source code
intelligentEditor.exe   Old Windows build
```
